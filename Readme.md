# Еmail-письма для аптечной сети «Сердце России»
Серия коммерческих медицинских email-писем (2 шт) для аптечной сети Сердце России. Проект реализован на React Email для поддержки в разных почтовых клиентах, в том числе Microsoft Outlook.

## 🛠 Технологический стек

### Frontend
- **HTML5** — табличная верстка для максимальной совместимости с почтовыми клиентами
- **JavaScript** — объекты стилей и массивы данных
- **React 19** — JSX для описания структуры


### Библиотеки и плагины
- **React Email** — компонентный подход к верстке email-писем с помощью компонентов React


## 🎯 Ключевые функции

### UI/UX элементы
- Два независимых шаблона на общей дизайн-системе:
	- **HeartOfRussian** — акционное письмо
	- **HeartOfRussianPromoCode** — письмо с промокодом
- Переиспользуемые компоненты
- Навигация с визуальными разделителями
- Баннеры с изображением акции
- Промокод для получения скидки
- Кнопка «Спешите в аптеки вашего города» для просмотра всего ассортимента товаров


### Совместимость с почтовыми клиентами
- **Gmail**
- **Mail.ru**
- **Яндекс.Почта**
- **Microsoft Outlook**


## 🔧 Технические особенности

### Ограничения email-клиентов и их решения
- **Навигация через `<Row>` и `<Column>`** — `<ul>` и `<li>` не работают в email
- **Разделители через символ `•`** — `::before` и `::after` не поддерживаются в Microsoft Outlook
- **Инлайн-стили** — внешние CSS вырезаются почтовыми клиентами


### Адаптивность
- Адаптивный дизайн
- Кросс-браузерная совместимость


**Проект демонстрирует навыки коммерческой email-разработки на React с использованием библиотеки React Email: компонентный подход к письмам, работу с табличной версткой, понимание ограничений почтовых клиентов (Microsoft Outlook, Gmail и др.), и создание единой дизайн-системы для нескольких шаблонов.**
